対応バージョン

Java 1.18.2 から 26.2 まで、19 プロトコルに対応済みです。クライアント × バックエンドは 19 × 19 = 361 通りです。最終目標は Java 1.0 から 26.3 までの全バージョン対応です。

対応済 エンジン（DetergentMC）で対応済み 作業中 実装中 予定 未着手

「対応済」はエンジン（DetergentMC）側でプロトコルレベルの検証（偽クライアントと本物のバニラサーバーによるテスト）が通っている状態です。本物のゲームクライアントでの確認は、まだどの組み合わせも行っていません。Surfactant の土台の段階で統合テスト済みのセルは 3 セル（偽 776 クライアントと偽 763 クライアントから実バニラ 26.2 へ、偽 763 クライアントから実バニラ 1.20.4 へ）です。
