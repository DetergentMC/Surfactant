製品

Surfactant はひとつのプロジェクトです。本体も、仕組みも、すべて公開・無料で進めています。

ダウンロード

ダウンロードできる jar はまだありません。準備中です。初回リリースの時期もまだ決まっていません。

  • 公開準備中：まだ何も配布していません。公開までは、ソースコードからビルドしてください。
  • リポジトリ：DetergentMC とは別のリポジトリで公開する予定です。GitHub の公開リポジトリも準備中です。

ソースコードからビルドする

開発段階のため、今はビルドから使ってください。JDK 17 で実行します。

$ JAVA_HOME=$HOME/workspace/.tools/jdk-17.0.21+9 \
  GRADLE_USER_HOME=$HOME/.gradle \
  JAVA_TOOL_OPTIONS="-Djava.net.preferIPv4Stack=true" \
  ./gradlew :surfactant-proxy:fatJar
$ java -jar surfactant-proxy/build/libs/surfactant-0.1.0.jar --workdir run

初回起動時に surfactant.yml の見本を作ります。バニラサーバーの jar は含みません。実行時に Mojang から取得します。

設定の例

バックエンドは backends に複数登録し、default-backend で既定の行き先を指定します。

# surfactant.yml（抜粋）
backends:
  - name: lobby
    host: 127.0.0.1
    port: 25566
    protocol: 776
  - name: survival
    host: 127.0.0.1
    port: 25567
    protocol: 763
default-backend: lobby

Surfactant 本体

DetergentMC の自前エンジンを使った BungeeCord式のプロキシサーバーです。Java で書かれています。ライセンスは DetergentMC と同じ MIT で、ソースコードは公開する予定です。

BungeeCord式

複数のバックエンド（ロビー・サバイバル・ミニゲームなど）をつなぎます。プレイヤーは既定のバックエンドに入り、/server で移動できます。

変換は手前で1回だけ

クライアントのプロトコルを、行き先のバックエンドのプロトコルに揃えてから渡します。後ろのサーバーは内部変換をしません。

全バージョン対応を目指す

Java 758〜776 の 19 プロトコルと Bedrock 30 プロトコルに対応済みで、最終的には Java 1.0 から 26.3 まで対応します。詳しくは対応バージョンをご覧ください。

日本語から始めて多言語へ

日本語のドキュメント・設定・サポートを土台に、英語をはじめ他の言語にも広げていきます。

使っているもの・使っていないもの

エンジンは何を使っていますか？
DetergentMC の自前実装（プロトコル翻訳・Bedrock 変換・認証）を、Gradle のコンポジットビルドで参照しています。DetergentMC のコードはコピーしていません。
本物の ViaVersion・Geyser・Floodgate は入っていますか？
入っていません。ViaVersion は GPL-3.0（組み込むと Surfactant も GPL-3.0 になる）、Geyser は単体プロキシとして設計されており、Floodgate はプラグイン形式のためです。Geyser風・Via風・Floodgate風の機能は、DetergentMC の自前実装が担います。
姉妹プロジェクトの DetergentMC とはどう違いますか？
DetergentMC はサーバーソフト（バニラを土台に独自 API で動くサーバー本体）で、Surfactant はプロキシ（複数のサーバーをつなぐ入口）です。Surfactant の後ろに DetergentMC を置くことも、バニラサーバーを置くこともできます。詳しくは DetergentMC の公式サイトをご覧ください。

正直な話

  • 開発段階です。本物のゲームクライアントでの確認はまだ行っておらず、テストはプロトコルレベルの検証です。実際のサーバー移動の実行はまだ次の段階です。
  • 有料版はありません。Surfactant は無料・公開前提のプロジェクトです。
