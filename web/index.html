Surfactant は DetergentMC の自前エンジンを使った、BungeeCord式の Minecraft プロキシサーバーです。
クライアントのプロトコルを、行き先のバックエンドのプロトコルに揃えてから渡します。
だから後ろのサーバーは自分のプロトコルで来た接続だけを受ければよく、内部変換がいりません。

目指すところ

1

変換は手前で1回だけ

サーバーが何台あっても、バージョン間の変換は Surfactant が手前で1回だけ行います。後ろのサーバーは内部変換をしません。

2

どのバージョンからでも入れる

最終目標は Java 1.0〜26.3 の全対応です。古いクライアントも、新しいクライアントも、同じ入口から入れるようにします。

3

Java も Bedrock も同じ入口に

Geyser風の変換と Floodgate風の認証を内蔵し、Bedrock のプレイヤーも Java のバックエンドに入れるようにします。Java アカウントがなくても入れます。

4

DetergentMC の姉妹プロジェクトとして

エンジンは DetergentMC の自前実装を使います。日本語のドキュメント・設定・サポートを土台に、英語をはじめ他の言語にも広げていきます。公開して色んな人に使ってもらうのが目標です。

正直な話

  • 本物のゲームクライアントでの確認は、まだどの組み合わせも行っていません。テストはすべてプロトコルレベルの検証（偽クライアントと本物のバニラサーバー）です。サーバー移動の実行など、実機での確認が必要な項目が残っています。
  • 開発段階です。土台ができたばかりで、実際のサーバー移動の実行やプレイヤーリストの統合はまだ次の段階です。ダウンロードできる jar もまだありません。
  • Bedrock には制限があります。インベントリはエンジン側で未対応で、Xbox 署名の検証や暗号化はまだありません。最新の Bedrock 26.60 / 26.62 には未対応です。
  • エンジンの制限も引き継ぎます。Java 側のチャンク翻訳は、ブロック値の誤訳の疑いがあることが分かっています（調査中です）。
